# 💰 Expense Tracker App

A simple Expense Tracker app built using React Native and Firebase.

---

## 🚀 Features

* 🔐 Login & Signup (Firebase Auth)
* 💾 Add / Edit / Delete Expenses
* 🔄 Real-time data (Firestore)
* 📊 Total expense calculation

---

## 🛠 Tech Stack

* React Native
* Firebase Authentication
* Cloud Firestore
